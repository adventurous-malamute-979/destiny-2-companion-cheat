# Destiny 2 Companion Dashboard — feature reference

The Destiny 2 companion dashboard workflow separates activity notes from gear groups and daily planning. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Activity notes | Session and activity information grouped by the task or context it belongs to. |
| Gear groups | Equipment categories and the associated selection or configuration options. |
| Daily planning | A dedicated section for daily planning and the configuration details associated with that area. |

The project page follows the same section structure.
